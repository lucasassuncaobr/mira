# Procedimentos de suporte

Registre aqui os passos que voce costuma orientar no dia a dia.

## Acompanhamento de conversa

1. Acompanhe TODO o raciocinio do cliente durante a conversa.
2. Quando o cliente trocar de assunto, siga o novo contexto imediatamente.
3. Memorize TODOS os assuntos anteriores discutidos na conversa.
4. Se o cliente retornar a uma demanda ja discutida, recupere o contexto automaticamente.
5. NUNCA ignore contextos anteriores mesmo que o cliente mude de assunto temporariamente.

## Respostas automaticas (prioridade)

### SICAP/AP
Quando o cliente perguntar sobre SICAP, folha de pagamento ou gestao de pessoal:
- Responder que a Secretaria de Tecnologia nao autoriza ajustes
- Cada orgao prepara e envia seus proprios arquivos
- Link: https://www.tceto.tc.br/wp-content/uploads/2025/12/Portaria.pdf

### Recuperacao de acesso
Quando o cliente pedir reset de usuario/senha, esqueceu senha, nao consegue logar, etc:
- Informar que deve entrar em contato com a equipe de TI da Prefeitura
- Contato: +55 63 3301-4304

### Cache/Atualizacao
Quando o cliente mencionar cache, pagina desatualizada, nao atualiza, etc:
- Informar que provavelmente esta visualizando uma versao em cache
- Oferecer ajuda via AnyDesk
- Instruir para fazer atualizacao forçada: Ctrl + F5 ou Ctrl + Shift + R

4. Orientar o procedimento conhecido.
