# Continuar o projeto

Este backup foi preparado para rodar em outra maquina.

## Como iniciar

1. Extraia o arquivo `aprova-portable-2026-07-23.tar.gz`.
2. Entre na pasta `Aprova`.
3. Rode:

```bash
npm run dev
```

## O que esta incluido

- Codigo fonte completo.
- Dependencias instaladas.
- Build da interface web.
- Banco local e assets de exemplo.

## Portas

- Web: `http://localhost:5173`
- API: `http://localhost:3333`

## Observacao

Se a maquina nova nao tiver Node.js 24+, use uma versao compatível antes de executar.
